# Security Policy

## Unterstützte Versionen

Sicherheitsupdates gibt es nur für die jeweils neueste Minor-Version (aktuell 1.6.x).

## Sicherheitslücke melden

Bitte **keine öffentlichen Issues** für Sicherheitslücken anlegen. Meldung bitte über
**Private Vulnerability Reporting** (Repo → Security → „Report a vulnerability“) oder direkt
an den Maintainer (GitHub: @KaiDeWitzka).

Hilfreich sind: betroffene Version, Schritte zur Reproduktion, erwartetes und tatsächliches Verhalten.
Eine erste Rückmeldung erfolgt in der Regel innerhalb von 7 Tagen.

Details zu den umgesetzten Schutzmaßnahmen: [docs/03-sicherheit.md](docs/03-sicherheit.md).
